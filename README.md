# 🚀 MyPage

A PHP-based community platform designed to bring together user management, discussion threads, messaging features, and customizable user settings in a structured and scalable web application.

## 📖 About

MyPage began as a simple web development project and gradually evolved into a complete community-oriented platform.

The project focuses on applying real-world web development practices, including organized project architecture, backend development with PHP, asset management, user interaction systems, and scalable code organization.

This repository represents both a functional application and a learning journey in modern web development.

## ✨ Features

* 👥 User management system
* 💬 Messaging functionality
* 🧵 Discussion threads and forum sections
* ⚙️ User and application configuration pages
* 🎨 Organized frontend assets
* 📱 Responsive design principles
* 🛠️ PHP-powered backend functionality
* 📂 Structured and maintainable project architecture

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/ab3leitor/MyPage.git
```

### Move the project into XAMPP

Place the project folder inside:

```text
C:\xampp\htdocs\
```

### Start XAMPP

Enable the following services:

* Apache
* MySQL (if required)

### Open the application

Navigate to:

```text
http://localhost/MyPage
```
